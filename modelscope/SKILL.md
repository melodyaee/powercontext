# 周边去哪儿 / Nearby Explorer

## 用途

把「我在 X，想找个 Y，走路别超过 N 分钟，推荐几家」转成一次真实数据驱动的地点推荐。

## 流程

1. 解析槽位：城市、起点经纬度、地点类型、步行时间上限（默认 20 分钟）、数量（≤3）、偏好。
2. 用 `maps_around` 或 `maps_text_search` 查询真实 POI；记录 id/name/address/location/type。
3. 对每个候选调用 `maps_direction_walking`，步行时间只取路线 `duration / 60`。
4. 丢弃类型不符或超过时间上限的地点；按偏好排序取前 `min(limit, 3)`。
5. 用固定表头输出：地点名称 | 地址 | 预计步行距离 | 预计步行时间 | 推荐理由。
6. 附一行：`数据来源：高德开放平台 POI 搜索 + 步行路径规划（本次实时查询）。`

## 异常处理

- 符合条件不足：少推荐并说明原因，不用超时地点凑数。
- 无结果：如实说明，建议放宽条件，不编造地点。
- 工具失败：重试一次；仍失败则明确说明无法给出可信推荐。
- 营业状态/排队/安静程度：标注「未核实」。

## 禁止

不写密钥；不编造地点/地址/距离/时间；不把直线距离当步行距离；不把超时地点列为符合条件。

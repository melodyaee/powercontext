# 验证样例 · 文献速读台

## 样例 A：首次使用

- **初始条件**：PowerContext 已启动并创建新 Scope；页面配置为全新 scope。
- **输入**：在「今天的阅读记录」输入 `关注 seekdb 的混合检索实现`。
- **步骤**：点「写入记忆」→ 刷新页面。
- **预期**：状态显示「已写入 PowerContext」；刷新后「我的关注点」区域显示刚才的文本。

## 样例 B：跨会话复用

- **初始条件**：保持同一 Scope，换浏览器或无痕窗口打开站点。
- **步骤**：填入相同服务地址与 Scope ID。
- **预期**：无需再次输入即可看到样例 A 的记录，证明 PowerContext 记忆被实际复用。

## 样例 C：异常

- **初始条件**：Scope ID 留空。
- **步骤**：点「写入记忆」。
- **预期**：状态显示「请先保存服务地址和 Scope ID」，不产生伪造记录。
